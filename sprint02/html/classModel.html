Detailed Description

Classe que representa o Modelo de simulação. A classe Model atua como o motor principal do simulador. Ela armazena coleções de sistemas (System) e fluxos (Flow) e orquestra a execução, garantindo a transferência correta de dados a cada passo de tempo.
