Detailed Description

Declaração das funções de testes funcionais do simulador.

  • Este arquivo contém os protótipos dos testes funcionais que validam o comportamento das simulações de fluxo Exponencial, Logístico e de Redes Complexas.

Executa o teste funcional complexo (cenário de rede).
