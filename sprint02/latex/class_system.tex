\doxysubsection{Detailed Description}
Classe que representa um Sistema no simulador. 


\begin{DoxyItemize}
\item A classe \doxylink{class_system}{System} é responsável por armazenar uma quantidade de \"{}massa\"{} ou \"{}energia\"{} que pode ser consumida ou incrementada pelos fluxos (\doxylink{class_flow}{Flow}) durante a execução do modelo. 
\end{DoxyItemize}
