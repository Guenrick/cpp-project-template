\doxysubsection{Detailed Description}
Implementacao concreta base da interface \doxylink{class_flow}{Flow}. 

Possui um identificador (id\+\_\+) e gerencia os ponteiros source e target. Implementa \doxylink{class_flow_impl_a06c8ffdcfd36b04ddad091d2c043f5d0}{get\+Source()}/get\+Target() (parte da interface \doxylink{class_flow}{Flow}) e tambem expoe set\+Source/set\+Target/clear\+Source/clear\+Target como metodos concretos — usados internamente pelo \doxylink{class_model}{Model} para (des)conectar Systems a um \doxylink{class_flow}{Flow}, ja que essas operacoes nao fazem parte da interface \doxylink{class_flow}{Flow}.

\doxylink{class_flow_impl_a88d14f759988f1dcf393b83a93aea1f1}{execute()} permanece abstrato para que cada tipo de fluxo defina sua propria equacao matematica.
